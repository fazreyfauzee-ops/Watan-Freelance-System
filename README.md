# Watan Freelance Platform

Watan Freelance Platform is a web-based system developed specifically for Universiti Kebangsaan Malaysia (UKM) students to support flexible, project-based freelance work. 

Problem Statement
- Students often face difficulties in finding suitable part-time work that matches their academic schedules, skill levels, and limited experience.
- Students must compete with external freelancers on existing platforms.
- There is currently no dedicated freelance platform tailored specifically for the UKM community.

Objectives
- To develop a specialized freelance platform that provides flexible work opportunities for UKM students.
- To include an efficient task management system within the platform.
- To improve project completion rates among student freelancers.

Tech Stack & Methodology
Methodology : Agile methodology using the Scrum framework (ensuring iterative development and continuous feedback).
Languages :  HTML, CSS, JavaScript, PHP
Databases :  MySQL

Key Features
- User Registration & Freelancer Profiles
- Service Listings
- Task Management System
- Communication Tools
- Payment Proof Upload
- Feedback Mechanisms

Project Outcome
The result of this project is a functional prototype that successfully supports student freelancing activities while maintaining flexibility, usability, and system effectiveness. It allows students to showcase their skills, manage freelance tasks efficiently, and gain real-world working experience.
